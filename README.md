A one-line office joke for make.fun's "Make the AI Judge Laugh" bounty, $2 in USDC. The program writes a single original joke about office life — under 200 characters — to `entry.txt` in the grader-supplied output directory, and nowhere else.

The joke: "My spirit animal is the office printer — I only work when someone threatens to replace me."

## Run it

```sh
python3 main.py /output
```

Test it locally first:

```sh
python3 main.py /tmp/test-output && cat /tmp/test-output/entry.txt
```
